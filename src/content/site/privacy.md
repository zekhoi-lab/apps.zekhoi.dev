## What this website collects

This is a static website. It has no accounts, no forms, and no cookies, and it does not load advertising or tracking scripts.

When you visit, the hosting provider receives the technical data any website receives: your IP address, browser user agent, the page requested, and the time. This data is used to deliver the site and protect it from abuse.
